# Task 6: K-Nearest Neighbors (KNN) Classification

This project implements the **K-Nearest Neighbors (KNN)** algorithm for classification using the **Iris dataset**. It includes data preprocessing, model training with different K values, evaluation, and visualization of decision boundaries.

---

## ✅ Objective

- Understand how the KNN algorithm works
- Normalize the dataset
- Train the model using different values of `K`
- Evaluate using accuracy and confusion matrix
- Visualize decision boundaries

---

## 🛠️ Tools & Libraries

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

## 📊 Dataset

- **Iris Dataset** (`Iris.csv`)
- Columns: `SepalLengthCm`, `SepalWidthCm`, `PetalLengthCm`, `PetalWidthCm`, `Species`

---
